## Como atualizar

Ao iniciar uma nova fase:

1. Crie um arquivo com o padrao `phase-N-short-name.md`.
2. Use linguagem simples.
3. Atualize este indice.
4. Atualize o indice geral em [../README.md](../README.md).
5. Marque o status com cuidado para diferenciar `Implementada` de `Concluida`.
